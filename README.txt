SPIRITUAL & MEDITATION SITE
===========================

Files:
- index.html: Complete website (HTML, CSS, AngularJS)

How to run:
1. Extract this ZIP file.
2. Open index.html in a web browser such as Google Chrome.
3. Keep an internet connection active because AngularJS is loaded from a CDN.

Features:
- Add and delete spiritual quotes
- Calculate meditation session duration in seconds
- Add and delete daily meditation activities

Note:
The meditation planner calculates the duration; it is not a live countdown timer.
